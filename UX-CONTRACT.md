# UX Contract — SOP Fieldguide

## Primary job

Help an operator find and apply the right general cross-border SOP, U.S. TikTok Shop execution step, Agent prompt, template, platform reference, or example.

## Navigation and state

- The home route explains both the upstream seven-agent path and the dedicated U.S. TikTok Shop route. The TikTok route begins with seller eligibility, before SKU or inventory work.
- The library route groups documents by method, Agent, shared template, example, and U.S. TikTok Shop.
- A selected document is encoded in the URL hash so it can be shared and restored.
- Search is local to the bundled repository material; it searches titles, paths, and document text.
- The document reader can copy content, download a Markdown copy, and open the canonical GitHub source.

## Source and compliance

- Display the upstream repository and MIT license attribution, while linking project-authored TikTok Shop documents to the user's repository.
- Bundle the maintained Markdown, YAML, and text guidance only.
- Do not bundle or expose the unedited source PDF referenced by the upstream README.
- Date-stamp official TikTok Shop policy snapshots. Live Seller Center instructions take precedence; no policy value is represented as live data.
- Show the U.S. seller eligibility limitation before launch actions. If an operator's legal route is not confirmed, the route is a stop, not a workaround.
- The fieldguide is a static manual workbench: it does not connect to TikTok accounts, read shop data, post content, or process orders.

## Accessibility

- Use semantic landmarks, native buttons and links, labeled search, visible keyboard focus, and responsive navigation.
- Respect reduced-motion preferences.
- Sanitize rendered Markdown HTML before insertion into the document.
