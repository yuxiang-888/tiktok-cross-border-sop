# 美国 TikTok Shop：执行手册

本栏目将上游的“输入 → 判断 → 产出 → 复盘”方法，落到美国 TikTok Shop 店铺运营。它是**静态手册与人工作业清单**，不会连接 TikTok 账号、读取店铺数据或自动发布内容。

> **先过准入闸。** TikTok Shop 美国卖家条款（2026-10-15 生效）写明适用范围为美国居民/美国实体，以及面向美国买家的日本跨境卖家。若经营主体在中国、没有已确认的合格美国实体或官方跨境路径，先暂停备货、广告和达人寄样，直接向 Seller Center 核实资格；不要借用身份、伪造地址或绕过审核。该条款范围可能更新，按注册当日官方要求执行。

## 执行路线

| 顺序 | 作业 | 必须交付 | 放行条件 |
|---|---|---|---|
| 00 | 经营主体与入驻资格 | 准入记录 | Seller Center 明确接受该主体与路线 |
| 01 | SKU 合规与商品页 | SKU 事实表、证据包、Listing QA | 商品可售，所需资质已批准 |
| 02 | 价格、佣金与单位经济 | 单件贡献利润表 | 扣除可变成本后仍符合经营者设定的底线 |
| 03 | 短视频内容生产 | Brief、脚本、发布前检查 | 视频与商品页、包装、真实功能一致 |
| 04 | 达人联盟合作 | Creator 筛选表、合作 Brief、结算记录 | 店铺/商品有资格，合作条款与披露清楚 |
| 05 | LIVE 运营 | Run of show、产品与库存清单 | 价格、库存、讲解证据和现场互动就绪 |
| 06 | 订单履约与售后 | 每日异常队列、退货原因记录 | 按 Seller Center 当前时限处理，物流可兑现 |
| 07 | 周复盘与实验 | 数据快照、变更日志 | 指标来自真实后台，下一轮只有明确假设 |

## 共同规则

1. 用英文面向美国消费者写商品信息；内部作业记录可以用中文，但产品事实要有来源。
2. 每个价格、折扣、库存、发货承诺、产品效果都要能回到 Seller Center、包装、测试或供应商文件。
3. 规则变化时，以 Seller Center 当前提示和 TikTok 官方政策页为准；本栏目是 2026-10-26 的核验快照，不是实时政策数据库。
4. 遇到禁止商品、待审批商品、入驻资格不明、知识产权不明、利润为负或发货 SLA 不可达，标记 **STOP**，不要用 AI 补猜。
5. 产品、税务、广告披露和消费者权利问题按具体 SKU 与经营主体咨询合格专业人士；本手册不是法律、税务或会计意见。
