# 00｜先核实美国站经营资格

**目的：** 在注册、备货、达人寄样或购买广告前，确认真实经营主体有可用的美国 TikTok Shop 入驻路径。这是 STOP/GO 闸，不是让 AI 推断资格。

## 输入

- 申请主体的注册国家/地区、法律形式、实际经营负责人所在地；
- Seller Center 当前显示的申请类型、资格提示和邀请/准入信息（若有）；
- 申请主体能合法提供的身份证明、企业文件、税务资料、收款账户、仓库和退货地址；
- 计划使用的店铺官方 TikTok 账号及其控制人。

不要把身份证件、税号、银行资料、登录密码或验证码粘贴进公开 Prompt、GitHub、工单或本手册。

## 操作

1. 打开官方 [美国 Seller Terms](https://seller-us.tiktok.com/university/essay?knowledge_id=1331308753078058)，确认条款生效日和适用主体。2026-10-15 生效版本列出美国居民/美国实体，以及面向美国消费者的日本跨境卖家。此范围不能推导出中国境内主体自动具备资格。
2. 用真实法律主体进入 [美国卖家注册流程](https://seller-us.tiktok.com/university/course?content_id=3396404588660481&learning_id=6033035939809038)。根据 Seller Center 当日要求，逐项核对身份/企业资料、税务、收款、仓库/退货地址、商品审核及官方账号关联。
3. 所有字段必须与申请主体的正式文件一致。遇到主体国家、所有权、税务表格或跨境物流不确定时，先通过 Seller Center 官方支持取得书面/工单确认；不要使用他人身份、虚假美国地址、借用店铺或伪造邀请信息。
4. 将官方申请结果、日期、工单编号（如有）、负责人和仍未解决的问题登记在本地企业记录中；公开手册只记录脱敏状态，不上传凭证。
5. 只有账号通过审核、Seller Center 中对应商品/履约路径可用后，才进入 SKU 放行和费用核算。

## 放行记录

| 字段 | 记录 |
|---|---|
| 主体法律名称 / 所在地 | 由经办人填写，不写进公开资料库 |
| 申请类型 / 官方路径 | 以 Seller Center 显示为准 |
| Seller Center 当前状态 | 待审核 / 通过 / 拒绝 / 需补件 |
| 官方规则复核日 / 链接 | 填写日期与条款 URL |
| 资格结论 | GO / STOP / 等待书面确认 |
| 批准人 / 证据位置 | 企业内部留存；不得公开敏感文件 |

## STOP 条件

- Seller Center 未接受该法律主体，或主体资料互相矛盾；
- 只能通过借用身份、虚假地址、代持账号或规避审查才能注册；
- 对税务、资金归属、商品进口与美国责任主体没有可核验答案；
- 负责人的资格判断只来自第三方课程、短视频或非官方代办。

STOP 时暂停不可逆投入；不得把后续 SOP 当成资格豁免。
